# 大氣密度模型與修正因子驗證

> 對應構想書議題四（大氣阻力模型與 STK／SDA 軌道計算介接）、架構書模型轉譯層。
> 本文記錄模型配置、修正因子定義、暴時 ap 模式的實測影響與**目前的驗證邊界**。

## 模型配置

| 項目 | 值 |
|---|---|
| 模型 | **MSIS 2.1**，經 `pymsis` 0.12 呼叫（該版預設即 2.1） |
| 地磁模式 | 暴時 ap 模式（`geomagnetic_activity=-1`，7 元素 ap 歷史） |
| F10.7 | 日值與 81 日中心平均，來源 CelesTrak／OMNI2 |
| ap 歷史 | 日均 Ap ＋ 當前／3／6／9 小時前 ap ＋ 12–33h、36–57h 平均 |
| 座標 | 預設 (0°N, 0°E)；常數偏差由 B_eff 自校準吸收。需絕對值時須傳入實際座標 |
| 高度範圍 | 80–1000 km（MSIS 有效域，超出即截斷） |
| 缺值處理 | F10.7 退回 120 sfu、ap 退回 10；ap 歷史任一項缺值時退回該時刻日均值 |
| 時間基準 | 全程 UTC |

輸出除密度值外，另保留模型版本、輸入資料時間、`ap_mode` 與
`calibrated_by_observation` 等 metadata（見 `services/exporter/drag_correction.py`）。

## 修正因子定義與 ap 模式

修正因子定義為同高度、同時刻的密度比：

```
storm_ratio = ρ(實際 F10.7, 實際 ap 歷史) ÷ ρ(同一 F10.7, 地磁寧靜 Ap=4)
```

分子與分母**固定使用相同的 UTC 時刻、經緯度、高度、F10.7 與模型版本**，
唯一改變的是地磁活動輸入（日均 Ap 與 3 小時 ap 歷史**兩者都換成寧靜值**）。

分母刻意固定在同一 F10.7。若改用太陽極小期為基準，太陽週期的貢獻會被
算進「事件效應」，在太陽極大期產生十倍以上的假修正。兩種比值都輸出，
但只有 `storm_ratio` 是軌道傳播該套用的那一個。

**`storm_ratio` 是模型內部的相對比較量，不是由觀測反演得到的密度校正係數。**
它回答的是「同樣條件下，把地磁輸入從寧靜換成實際值，MSIS 的密度會變幾倍」，
不代表真實大氣的實際倍率。要成為觀測校正係數，需接上精密星曆反演密度
（架構書 A9）後重新校準。

模型為 **MSIS 2.1**，經 `pymsis` 0.12 呼叫（該版預設即 MSIS 2.1）。
本文件所有「MSIS 2.1」均指此執行配置；README 其他處提及的 `NRLMSISE-00`
一律是指 **STK/HPOP 使用者端可選的大氣模型選項**，不是本系統的計算模型。
採**暴時 ap 模式**
（`geomagnetic_activity=-1`，傳入 7 元素 ap 歷史）。這點值得說明：
MSIS 在預設模式下**只讀日均 Ap**，3 小時解析度完全進不到模型。改用暴時模式後，

- 暴起始與恢復期的密度差異最大達 **53%**
- 更重要的是消除了**物理層的前視洩漏**：日均 Ap 是該 UT 日 8 筆 3 小時 ap 的平均，
  因此 2024-05-10 的日均值本身就含有當天 17:00 之後才發生的擾動。
  用它計算當天稍早的密度，等於把尚未發生的事算進去；於該日 00:00Z、400 km
  的估計虛高約 **35%**

上述兩個百分比的比較條件：**2024-05-08～14 期間、400 km、臺灣上空座標
（23.5°N/121°E）、相對日均 Ap 模式的密度比值差**。此為本案例的結果，
不代表其他高度、日期或太陽活動條件下的固定誤差。

2024-05 Gannon 事件的實測結果（暴時 ap 模式）：

| 高度帶 | 峰值 storm_ratio |
|---|---|
| 300–400 km | 2.24× |
| 400–500 km | 2.90× |
| 500–600 km | 3.67× |

400 km 密度自 4.6×10⁻¹² 升至 1.1×10⁻¹¹ kg/m³（2.56×，峰值 2024-05-11 03:00Z）。

輸出的 JSON 帶 `model`、`baseline`、`ap_mode`、`calibrated_by_observation` 等
metadata；`uncertainty` 為**經驗保守值**，非實測誤差棒，尚未由觀測反演校準。


## 驗證邊界

**已完成**：

- 單元測試涵蓋 ap 歷史的 7 元素順序、前視洩漏檢查、暴時／日均模式差異、
  平靜基準污染檢查、密度隨高度遞減（`tests/test_density.py`）
- 2024-05 Gannon 事件的物理合理性檢查（量級與時序符合公開報導）

**未完成**：

- **未與精密星曆反演密度交叉校準**。`storm_ratio` 目前純為模型內部相對量。
  接上 Sat_TraingDataExtension 的能量耗散法密度反演（架構書 A9）後，
  才能以 ρ_obs/ρ_model 的實測散布取代目前的經驗不確定度。
- **未與 STK/HPOP 的傳播結果比對**。CSSI 驅動檔格式已驗證，
  但兩端的密度與軌道結果是否一致尚未量測。
- **不確定度為經驗保守值**，非實測誤差棒。公式見 `_uncertainty()`，
  依 Ap 強度與擾動倍率遞增，屬工程保守設定而非統計推導。

## 模型間交叉比對（模型系統誤差的下界）

`storm_ratio` 是模型內部的相對量，無法自我驗證。在取得實測反演密度之前，
**換一個模型算同一件事**至少能給出「模型選擇本身造成多少差異」的量級。

pymsis 可用 `version=0` 切換到 NRLMSISE-00。於 2024-05-08→14、
lat 0°／lon 0°、每 3 小時取樣、暴時 ap 模式下的期間峰值密度：

| 高度 | MSIS 2.1 | NRLMSISE-00 | 相對差 |
|---|---|---|---|
| 350 km | 3.272×10⁻¹¹ | 3.530×10⁻¹¹ | −7.3% |
| 450 km | 8.845×10⁻¹² | 9.620×10⁻¹² | −8.1% |
| 550 km | 2.740×10⁻¹² | 3.005×10⁻¹² | −8.8% |

**如何解讀**：7–9% 是**模型間分歧**，不是誤差。真實誤差不會小於這個量級，
但也不等於這個量級——兩個模型可能同向偏離實測。
作為參照，文獻記載 HASDM 在 200–800 km 的誤差為 6–8%
（見 [research_review.md](research_review.md) §3.2）。

本專案 `_uncertainty()` 目前給的平靜期基礎不確定度為 15%，
相對上述數字屬保守，但**仍是經驗值而非校準值**。
改用文獻校準方法的建議見 [research_review.md](research_review.md) §3.1。
