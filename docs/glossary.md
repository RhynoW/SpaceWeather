# 太空天氣名詞與參數判讀

> 給第一次接觸太空天氣的讀者、教育推廣場合，以及需要看懂本系統輸出的值勤人員。
> 不需要物理背景。每個參數都附「多少算大」與「常見誤讀」。
>
> 系統實際提供的參數以 `configs/params.yaml` 為準（目前 44 個），
> 本文說明其中最常被引用的部分。

---

## 零、先看懂這條因果鏈

太空天氣不是單一現象，是一條**從太陽出發、影響地面與軌道系統**的因果鏈。
看懂這條鏈，就知道每個參數量的是鏈上哪一段：

```
太陽表面           行星際空間          地球磁層          電離層／熱氣層        我方系統
活動區、閃焰   →   太陽風、IMF   →   地磁擾動      →   電子密度、大氣密度  →  通信／定位／軌道
（F10.7、X 射線）  （Bz、速度）      （Kp、Dst）       （TEC、S4、ρ）         （L0–L4 判讀）
```

**三種擾動的抵達時間完全不同**，這是判讀時最關鍵的一件事：

| 擾動 | 本質 | 抵達時間 | 有無預警空間 |
|---|---|---|---|
| 電磁輻射（X 射線、紫外線） | 光 | **8 分 20 秒** | **沒有**。看到閃焰時影響已同時發生 |
| 高能質子（SEP） | 近光速粒子 | 數十分鐘～數小時 | 很短 |
| 日冕物質拋射（CME） | 電漿雲團 | **1–3 天** | 有，這是地磁暴預警的主要來源 |

所以「太陽閃焰預警」與「地磁暴預警」是兩件難度天差地遠的事——
前者幾乎不可能提前，後者才是預報引擎的主戰場。

## 一、名詞說明

### 太陽端

**太陽黑子（Sunspot）／活動區（Active Region, AR）**
太陽表面磁場強烈集中的區域，看起來較暗（因為磁場抑制了對流帶來的熱）。
大部分閃焰與 CME 都從活動區發出，所以活動區的數量、面積與磁場複雜度
是判斷「未來幾天會不會出事」的主要線索。

**太陽閃焰（Solar Flare）**
活動區的磁力線重新連接（磁重聯），把儲存的磁能在幾分鐘內釋放出來，
產生 X 射線與紫外線爆發。**以光速抵達**，主要影響向陽面的電離層 D 層。
依 X 射線峰值強度分為 A／B／C／M／X 五級，**每級差 10 倍**，
同級內再以 1–9.9 細分（如 M5.2、X1.0）。

**日冕物質拋射（CME, Coronal Mass Ejection）**
太陽拋出的大量磁化電漿。速度約每秒數百至兩千公里，
抵達地球需 1–3 天。若其磁場方向與地球磁場相反（南向 Bz），
就會有效率地把能量灌進磁層，引發地磁暴。**CME 才是大地磁暴的主因**，
閃焰只是常與 CME 一起發生的伴隨現象。

**太陽週期（Solar Cycle）**
約 11 年的活動盛衰週期。極大期時閃焰頻繁、F10.7 高、大氣膨脹、低軌衛星壽命縮短。
判讀任何「異常」前，都要先問：這是事件效應，還是只是處在太陽極大期？

### 傳播與行星際空間

**太陽風（Solar Wind）**
太陽持續吹出的電漿流，平時速度約 300–500 km/s，高速流可達 700–800 km/s。

**行星際磁場（IMF）與 Bz**
太陽風帶著的磁場。**Bz 是它的南北分量，是整條鏈上最關鍵的單一參數**：
- Bz **向北（正）**：與地球磁場同向，互相排斥，能量進不來，通常平靜。
- Bz **向南（負）**：與地球磁場反向，發生磁重聯，能量大量注入 → 地磁暴。

一句話記：**「南向 Bz 才會出事」**。看到太陽風速度飆高但 Bz 持續向北，
通常不會有大地磁暴。

### 地球磁層與地磁

**地磁暴（Geomagnetic Storm）**
太陽風能量注入磁層後，環電流增強、地表磁場被壓低的全球性擾動，
可持續數小時至數天。

**Kp 指數**
全球 13 個中緯度地磁觀測站的擾動幅度綜合而成，**每 3 小時一個值**，
範圍 0–9，**準對數尺度**（不是線性！Kp 從 8 到 9 的能量差遠大於 0 到 1）。
定義在**三分位**上：0、1/3、2/3、1、4/3…，
所以你會看到 4.67（寫作 5−）這種值，這是規格而非誤差。

**ap 指數與 Ap**
`ap` 是 Kp 的**線性**版本，單位 nT，同樣每 3 小時一個值，範圍 0–400。
`Ap` 是一天 8 個 ap 的**日平均**。
需要做算術（平均、餵進大氣模型）時必須用 ap／Ap，**不能對 Kp 取平均**——
對準對數量取算術平均沒有物理意義。

**Hp30／ap30**
Kp／ap 的 **30 分鐘解析度**版本。3 小時的 Kp 會把暴起始時刻糊掉 1–2 小時，
對「提前量」這種以小時計的指標影響很大。
注意 **Hp30 可以超過 9**（可達約 12）——因為較短的時間窗會抓到被 3 小時平均削平的尖峰，
這不是資料錯誤。

**Dst 指數**
赤道環電流強度，單位 nT，**地磁暴時為負值**，逐時更新。
它比 Kp 更直接反映「環電流被灌入多少能量」。
`SYM-H` 是它的 1 分鐘解析度版本。

**極光橢圓（Auroral Oval）與赤道側邊界**
極光發生的環狀區域。擾動越強，這個環**向赤道擴張**得越低緯。
「赤道側邊界緯度」因此是擾動深入程度的直觀指標——
邊界壓到什麼緯度，就代表該緯度以上的 HF 通信與 GNSS 開始受影響。

**地磁緯度 vs 地理緯度（判讀臺灣時必看）**
地球磁場的軸與自轉軸不重合。**電離層現象依地磁緯度分布，不依地理緯度**。
臺灣地理緯度約 23.5°N，但**地磁緯度僅約 19°N**——
正落在「赤道異常駝峰區」，這是全球電離層最劇烈、閃爍最強的地帶之一。
**用地理緯度判斷臺灣的電離層風險會系統性低估。**

### 電離層

**電離層（Ionosphere）與分層**
高度約 60–1000 km 的帶電層，由太陽輻射電離大氣而成。分層各有脾氣：

| 層 | 高度 | 對通信的作用 | 何時出問題 |
|---|---|---|---|
| **D 層** | 60–90 km | **吸收** HF 電波 | 閃焰時劇烈增強 → HF 中斷（日側） |
| **E 層** | 90–150 km | 反射較低頻 | 偶發 E 層 |
| **F 層**（F2） | 150–500 km | **反射** HF，決定可用頻率上限 | 暴時劇烈變化；閃爍主要發生地 |

記憶法：**D 層吃掉訊號，F 層彈回訊號**。

**foF2（F2 層臨界頻率）**
垂直發射時 F2 層還能反射回來的**最高頻率**，單位 MHz。
斜向發射可用的最高頻率（MUF）約為 foF2 的 3 倍左右。
foF2 掉下來，可用的 HF 頻段就變窄。

**TEC（總電子含量）**
一條「地面→衛星」路徑上每平方公尺柱體內的電子總數，
單位 **TECU**（1 TECU = 10¹⁶ 電子/m²）。
它直接造成 GNSS 測距誤差：**在 GPS L1 頻率上，1 TECU ≈ 0.16 公尺延遲**。
所以 50 TECU 的電離層若未修正，就是 8 公尺的定位偏差。

**閃爍（Scintillation）：S4 與 ROTI**
電離層中的不規則體讓訊號快速起伏。這與 TEC 是**兩件不同的事**：
- **TEC 大** → 測距有系統性偏差，但可用模型或雙頻修正。
- **閃爍強** → 訊號**忽強忽弱甚至失鎖**，修正不了，只能等它過去。

`S4` 量振幅起伏（0 至 1 以上），`ROTI` 量 TEC 的變化率（TECU/分）。
**赤道異常區（含臺灣）的閃爍好發於日落後數小時**，這是本地判讀的重點時段。

**D 層吸收與 D-RAP**
閃焰時 D 層電子密度暴增，HF 電波穿過時被吸收。
SWPC 的 **D-RAP** 產品直接給出「因吸收而不可用的最高頻率」（MHz）——
這個數字以下的頻率都被吃掉了，數字越高代表中斷越嚴重。

### 熱氣層與軌道

**熱氣層密度（ρ）與大氣阻力**
地磁暴會加熱高層大氣使其膨脹，**同一高度的空氣變濃**。
低軌衛星受到的阻力正比於密度，因此暴時掉高更快、軌道預測誤差變大。
2022 年 2 月 SpaceX 一批 Starlink 衛星在發射後遇上地磁暴、
因阻力遽增而未能進入預定軌道，是最著名的實例。

**彈道係數（B）**
衛星「多容易被空氣拖住」的參數，約等於 阻力係數×截面積÷質量。
面積質量比大的衛星（如展開太陽帆板的立方衛星）受影響大得多。

## 二、分級尺度：三套不同的東西，別混用

| 尺度 | 誰定的 | 量什麼 | 依據 |
|---|---|---|---|
| **G1–G5** | NOAA | 地磁暴強度 | **Kp**（G1=Kp5、G2=Kp6、G3=Kp7、G4=Kp8、G5=Kp9） |
| **R1–R5** | NOAA | 無線電衰減 | **GOES X 射線峰值通量**（R1=M1、R2=M5、R3=X1、R4=X10、R5=X20） |
| **S1–S5** | NOAA | 太陽輻射風暴 | **≥10 MeV 質子通量**（S1=10 pfu，每級 ×10） |
| **L0–L4** | **本系統** | **任務風險** | 本案自訂門檻，見 `configs/rules/*.yaml` |

**G/R/S 描述的是「環境事件有多強」，L0–L4 描述的是「對我方任務有多大影響」。**
兩者不能互相換算，也不會同步：一場 G4 地磁暴對地面單位可能只是 L1，
對低軌操作單位可能是 L4。系統把它們放在事件卡的**兩個獨立欄位**
（`international_scale` 與 `mission_level`），刻意不做對應表。

## 四、常見誤讀（這節最重要）

**1.「Kp 平均 4，所以還好」**
Kp 是準對數量，**不能取算術平均**。一天內 Kp 走 2-2-2-8-8-2-2-2 與全天平穩 4，
物理意義完全不同。要做平均請用 ap。

**2.「沒有告警，所以安全」**
本系統刻意區分**「沒事」與「沒資料」**。規則若回報 `unavailable`，
代表判定所需的資料源不存在，**不是風險為零**。
儀表板對此顯示灰色「無資料」而非綠燈，就是為了避免這個誤讀。

**3.「有 X 級閃焰，快發地磁暴警報」**
閃焰的 X 射線 8 分鐘就到，影響的是**日側 HF**；
地磁暴要等 CME 走 1–3 天，且**只有 Bz 南向才會發生**。
大閃焰未必伴隨地磁暴，無閃焰也可能因冕洞高速流而地磁暴。

**4.「臺灣在低緯，電離層風險低」**
**恰恰相反**。臺灣地磁緯度約 19°N，位於**赤道異常駝峰**，
是全球 TEC 最高、閃爍最強的區域之一。低緯不等於低風險。

**5.「TEC 高就會失鎖」**
TEC 高造成的是**可修正的測距偏差**；讓接收機失鎖的是**閃爍**（S4／ROTI）。
兩者常同時發生但機制不同，處置方式也不同。

**6.「模型算出來的就是實測」**
本系統嚴格區分兩者。凡屬推估的量一律標 `is_proxy=True` 或
事件卡的 `inference: proxy`，並傳遞到 API 與儀表板。
IGRF 地磁基準場、MSIS 密度、`storm_ratio` **全部是模型輸出**，
目前皆未與在地實測逐點比對。
事件卡的 `inference` 欄位就是為此而設：`observed`／`modelled`／`proxy`／`unavailable`
四值明確區分，**永不為 null**——因為 `null` 最容易被誤讀成「已觀測證實」。

**7.「歷史回測命中率很高，所以預報可信」**
若回測時用到了「當時還不知道」的事後訂正資料，命中率會虛高。
本系統以**雙時間軸**（`valid_time` 物理時間／`ingest_time` 入庫時間）防止此事，
`as_of` 查詢只回傳該時刻**已經入庫**的資料。
順帶一提，本系統目前的 48 小時預報**未通過基線門檻**，
訓練折與測試折的落差顯示存在過擬合——這寫在
[forecast_verification.md](forecast_verification.md) 裡，沒有藏起來。

**8.「G5 就一定是最高等級警報」**
G/R/S 是**環境強度**，L0–L4 是**任務影響**。
同一場 G5 對不同單位的任務影響可以差很多，
所以系統不提供兩者的換算表。

## 五、系統術語

| 術語 | 意思 |
|---|---|
| **Nowcast（即時分析）** | 對**當前**狀態的判定，用已到手的觀測。不是預測。 |
| **Forecast（預報）** | 對**未來**時刻的推估。本系統做 1–48 小時 Kp。 |
| **valid_time** | 資料描述的**物理時間**（這個 Kp 是幾點的 Kp）。 |
| **ingest_time** | 資料**進到系統**的時間（我們幾點才知道）。 |
| **as_of 回放** | 只使用「某時刻之前已入庫」的資料重跑，用來誠實評估當時能做出什麼判斷。 |
| **前視偏差（Lookahead bias）** | 不慎用到未來資訊，使績效虛高。雙時間軸就是為了防它。 |
| **inference（判定依據）** | 事件卡每個影響分項都帶此欄位，**永不為 null**，四選一：`observed` 直接觀測／`modelled` 模型或預報輸出／`proxy` 間接推估／`unavailable` 判定所需資料不存在。**收到 `null` 或缺欄位時不得自動解讀為 observed**。 |
| **proxy（推估）** | 非直接觀測，而是由其他量間接推算。系統一律明確標示。 |
| **degraded（劣化）** | 來源仍可取得，但資料齡期超出該參數的更新週期，**新鮮度不足**。 |
| **POD（命中率）** | 實際發生的事件中，被成功預報的比例。越高越好。 |
| **FAR（誤報率）** | 所有發出的警報中，實際沒發生的比例。越低越好。 |
| **CSI** | 綜合 POD 與 FAR 的單一指標，不受「正確否定」灌水影響。 |
| **BSS（Brier Skill Score）** | 機率預報相對「永遠報氣候頻率」的技巧。**負值代表不如直接報氣候值**。 |
| **基線（Baseline）** | 不用機器學習的簡單作法（持續性、氣候平均、27 日復現）。新模型贏不過基線就沒有上線價值。 |
